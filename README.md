Descripción

Un proyecto en Python para crear y probar expresiones regulares. Contiene lógica en controladores/ y modelos en modelos/. Este README guía la instalación, uso y cómo lanzar una interfaz gráfica simple creada para facilitar la interacción.

Requisitos

Python 3.8+ (recomendado 3.10)

# clonar repo
git clone https://github.com/Makkima16/Expresiones_Regulares.git
cd Expresiones_Regulares


Uso (línea de comandos)
# ejecutar el entrypoint actual
python main.py

Uso (interfaz gráfica)
python gui.py
